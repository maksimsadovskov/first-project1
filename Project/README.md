# VK Маруся - Платформа фильмов

Веб-приложение для просмотра и управления фильмами, созданное на React.

## Функциональность

### Основные страницы:
- **Главная страница (Dashboard)** - случайный фильм и топ-10 фильмов по рейтингу
- **Страница жанров** - список всех доступных жанров
- **Страница конкретного жанра** - фильмы определенного жанра с пагинацией
- **Страница фильма** - подробная информация о фильме
- **Страница аккаунта** - управление избранными фильмами и настройки

### Функции:
- ✅ Авторизация и регистрация пользователей
- ✅ Поиск фильмов
- ✅ Добавление фильмов в избранное
- ✅ Просмотр трейлеров в модальном окне
- ✅ Адаптивный дизайн
- ✅ Темная тема

## Технологии

- React 18
- TypeScript
- Redux Toolkit
- React Router DOM
- CSS3 (Flexbox, Grid)
- Local Storage для хранения данных пользователя

## Быстрый запуск

**Требования:** Node.js 14+

### Для куратора:

1. Перейдите в папку `Project`:
```bash
cd Project
```

2. Установите зависимости:
```bash
npm install --legacy-peer-deps
```

3. Запустите приложение:
```bash
npm install
npm start
```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

**Примечание:** Используется флаг `--legacy-peer-deps` для установки зависимостей из-за конфликта версий TypeScript. Также добавлен `vite.config.ts` для совместимости с различными системами сборки.

## Использование

### Авторизация
- Нажмите "Войти" в правом верхнем углу
- Заполните форму входа или переключитесь на регистрацию
- Все поля обязательны для заполнения

### Поиск фильмов
- Нажмите на иконку поиска в шапке сайта
- Введите название фильма в поле поиска
- Результаты отображаются в реальном времени

### Избранные фильмы
- Нажмите на кнопку ♥ на карточке фильма
- Для неавторизованных пользователей откроется форма входа
- Управляйте избранными фильмами в разделе "Мой аккаунт"

### Просмотр трейлеров
- На странице фильма нажмите "Смотреть трейлер"
- Трейлер откроется в модальном окне

## Особенности реализации

- **Валидация форм** - все поля проверяются на заполненность и корректность
- **Адаптивный дизайн** - приложение корректно работает на всех устройствах
- **Локальное хранение** - данные пользователя сохраняются в localStorage
- **Модальные окна** - удобные всплывающие окна для различных действий
- **Пагинация** - на страницах жанров реализована подгрузка контента при скролле

## Демо данные

Приложение использует демо данные для фильмов и жанров. В реальном приложении эти данные загружались бы с сервера через API.
